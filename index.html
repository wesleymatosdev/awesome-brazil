Sobre este hub

Este é um hub colaborativo de iniciativas de tecnologia. É um projeto 100% aberto: o catálogo vive em um arquivo de dados versionado, o código do site é livre (MIT) e qualquer pessoa pode contribuir.

Como funciona: cada card aponta para uma iniciativa independente, mantida por suas próprias pessoas desenvolvedoras. O hub apenas organiza e conecta — não somos autores nem mantemos o que está listado.

Como contribuir: envie uma iniciativa abrindo um pull request que adiciona uma entrada em data/apps.json (o guia está em CONTRIBUTING.md), ou sugira via issue se preferir não mexer em código. Toda entrada passa por validação automática antes de entrar no ar.

Cuidamos para que nada indevido permaneça listado: a lista é revisada pela comunidade, e qualquer pessoa pode reportar um problema abrindo uma issue.
