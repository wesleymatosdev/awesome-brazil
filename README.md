# Awesome Iniciativas [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[![Validação](https://github.com/wesleymatosdev/awesome-iniciativas/actions/workflows/validate.yml/badge.svg)](https://github.com/wesleymatosdev/awesome-iniciativas/actions/workflows/validate.yml)

> Uma lista curada de iniciativas brasileiras de tecnologia aberta 🇧🇷 — dados abertos, civic tech, comunidades e ferramentas feitas em comunidade.

## Dados abertos

- [Brasil.IO](https://brasil.io) - Datasets públicos brasileiros tratados e gratuitos: torna dados públicos acessíveis em formato analisável para qualquer pessoa. ([código](https://github.com/turicas/brasil.io))
- [Querido Diário](https://queridodiario.ok.org.br) - Plataforma que abre os diários oficiais dos municípios: busca unificada em publicações normalmente dispersas e em PDF. ([código](https://github.com/okfn-brasil/querido-diario))

## Comunidades

- [Open Knowledge Brasil](https://ok.org.br) - Organização sem fins lucrativos que desenvolve e apoia projetos de dados abertos, transparência e conhecimento livre no Brasil. ([código](https://github.com/okfn-brasil))
- [Python Brasil](https://python.org.br) - Comunidade de pessoas que usam Python no Brasil: eventos, grupos locais, código de conduta e iniciativas de inclusão. ([código](https://github.com/pythonbrasil))

## Ferramentas

- [Operação Serenata de Amor](https://github.com/okfn-brasil/serenata-de-amor) - Projeto open source que usa ciência de dados para auditar gastos públicos do Congresso Nacional de forma colaborativa. ([código](https://github.com/okfn-brasil/serenata-de-amor))

## Contribua

Contribuições são bem-vindas! Leia o [CONTRIBUTING.md](CONTRIBUTING.md) — em resumo:

- Sabe usar Git? Abra um PR adicionando sua iniciativa à seção certa (o formato está documentado lá).
- Não mexe com código? [Abra uma issue](https://github.com/wesleymatosdev/awesome-iniciativas/issues/new?template=nova-iniciativa.yml) com o template **Nova iniciativa**.

Todo PR passa por validação automática ([awesome-lint](https://github.com/sindresorhus/awesome-lint) + verificação de links) antes do merge.

## Critérios

Uma iniciativa entra na lista quando:

1. É real, acessível e mantida ativamente (ou com relevância histórica clara).
2. Tem relação com tecnologia aberta, dados abertos ou colaboração no Brasil.
3. Não é duplicata de algo já listado.
4. O link funciona (HTTPS) — verificado automaticamente no CI.
